## НАСТРОЙКА

Указать время для теста

```typescript
test.setTimeout(600000); // 10 минут
test('Описание', async ({ page, request }) => {
	test.setTimeout(0); // отключить ограничение по времени
}
```

Ожидание объекта

```typescript
await page.waitForSelector('table');
```

## ПРОВЕРКА

Проверить видимость объекта во фрейме

```typescript
const frame = await page.frameLocator('//iframe');
await expect(frame.locator("//h3")).toBeVisible();
```

Проверка отображения объекта с ожиданием

```typescript
await expect(page.locator("//header")).toBeVisible();
await expect(page.locator("//ul/li").first()).toBeVisible();
await expect(page.locator("//ul/li").first()).toBeVisible({ timeout: 10000 });
```

Проверить что объект НЕ отображается

```typescript
await expect(field.locator("//a[@disabled='disabled']")).not.toBeVisible();
await expect(field.locator("//a[@disabled='disabled']")).toBeHidden();
await expect(field.locator("//a[@disabled='disabled']")).toHaveCount(0);
```

Проверка количества

```typescript
const rowCount = await page.locator("//ul/li").count();
await expect(rowCount).toBeGreaterThan(1);
await expect(rowCount).toBe(3);
```

Проверить текст заголовка

```typescript
const article = await page.locator("//div[@class='item']").first();
const article_name = (await article.locator("//a").textContent()) ?? "";
const h1 = page.locator("//h1");
await expect(h1).toHaveText(article_name);
await expect(h1).toContainText(article_name);
```

Проверить URL

```typescript
const response = await page.request.get(Helper.URL + href, { timeout: 10000 });
await expect(response.status()).toBe(200);

// в файле playwright.config.ts нужно добавить
use: {
	ignoreHTTPSErrors: true, // Ignore HTTPS errors for self-signed certificates
},
```

## ДЕЙСТВИЕ

Скролл - прокрутка в конец страницы

```typescript
await page.evaluate(() => window.scrollTo(0, document.body.scrollHeight));
await expect(page.locator('.container--e1').first()).toBeVisible({ timeout: 10000 });
```

Скролл к кнопке внутри поп-апа

```typescript
await popup.locator("//button").scrollIntoViewIfNeeded();
```

Нажатие на объекта

```typescript
await page.getByText('Найти туры').click();
await page.getByText('Найти', { exact: true }).click();
await page.getByRole('button', { name: 'Отправить' }).click();
```

Заполнение формы

```typescript
await page.getByPlaceholder('Введите имя').fill('Иванов Иван Иванович');
await page.locator('input[name="serial"]').fill('1234567890');
```

Посимвольный ввод в поле

```typescript
await popup.locator("//input[@name='name']").pressSequentially('John', { delay: 100 });
```
