Получить значение "ЗадачаСсылка" из выделенной строки

```1c
&НаКлиенте
Процедура ПерейтиПоСсылке(Команда)
	ТекущиеДанные = Элементы.Список.ТекущиеДанные;
	Если ТекущиеДанные = Неопределено Тогда
		Сообщить("Пожалуйста, выберите строку.");
		Возврат;
	КонецЕсли;
	
	Ссылка = ТекущиеДанные.ЗадачаСсылка; 
	
	Если НЕ ЗначениеЗаполнено(Ссылка) Тогда
		Сообщить("Ссылка в выбранной строке не заполнена.");
		Возврат;
	КонецЕсли;
	
	ПерейтиПоНавигационнойСсылке(Ссылка);
КонецПроцедуры

```
